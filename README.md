# 🚗 PID-Based Line Follower Robot using ESP32

An autonomous line-following robot built using an **ESP32**, **TB6612FNG Motor Driver**, and an **8-channel SmartElex RLF-081R IR Sensor Array**. The robot implements a **PID (Proportional–Integral–Derivative) control algorithm** to continuously calculate its position relative to a black line and dynamically adjust the speed of each motor for smooth, accurate, and stable navigation.

---

## 📌 Features

* PID-based line following
* 8-channel infrared sensor array for accurate line detection
* Dynamic speed adjustment for sharp turns
* Automatic line-loss recovery
* Dead-zone compensation for DC motors
* Differential drive control
* PWM-based motor speed regulation
* Lightweight and efficient TB6612FNG motor driver

# Working Principle

The infrared sensor array continuously detects the position of the black line beneath the robot.

Each sensor is assigned a positional weight ranging from **-4 to +4**, allowing the controller to estimate the position of the line with respect to the center of the robot.

The calculated position error is passed into a PID controller, which computes the required steering correction.

Motor speeds are then adjusted independently using PWM signals generated by the ESP32.

When the robot enters a sharp curve, the controller automatically reduces the base speed, improving stability and preventing overshoot.

If the line is lost completely, the robot rotates in the direction of the previous error until the line is detected again.

---

# PID Algorithm

The controller uses the standard PID equation:

```
Output = Kp × P + Ki × I + Kd × D
```

Where

* **P (Proportional)** corrects the current error.
* **I (Integral)** removes accumulated steady-state error.
* **D (Derivative)** predicts future error and reduces oscillations.

Current PID tuning:

```
Kp = 8.5
Ki = 0.001
Kd = 15.0
```

---

# Sensor Weighting

```
Sensor

D1  D2  D3  D4  D5  D6  D7  D8
-4  -3  -2  -1  +1  +2  +3  +4
```

These weights are averaged to determine the robot's deviation from the center of the line.

---

# Motor Control Logic

The left and right motor speeds are calculated as

```
Left Speed  = Base Speed + PID Correction

Right Speed = Base Speed - PID Correction
```

This differential drive mechanism enables smooth steering without stopping either motor.

---

# Dynamic Speed Control

The robot automatically adjusts its base speed depending on the detected error.

| Error Magnitude    | Base Speed |
| ------------------ | ---------: |
| Small              |        160 |
| Large (Sharp Turn) |        120 |

This improves stability while maintaining high speed on straight sections.

---

# Line Recovery

If no sensor detects the line,

* the previous steering direction is remembered,
* the robot rotates toward that direction,
* normal PID control resumes once the line is found.

---

# Motor Dead-Zone Compensation

DC motors typically do not rotate at very low PWM values.

To overcome this, a minimum PWM threshold of **60** is applied whenever a motor is commanded to move.

This prevents motor stalling during slow corrections.
